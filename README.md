# TNV Hub

This repository maintains separate branches for the frontend and backend architectures:

- **Frontend:** Switch to the [`frontend`](../../tree/frontend) branch for the user interface, React application (`client/`), design tokens, and reference implementations.
- **Backend:** Switch to the [`backend`](../../tree/backend) branch for the Node.js server, Supabase schema migrations, data models, and automated test suites.

---

### Branch Overview

| Branch | Description |
| :--- | :--- |
| **`frontend`** | Modern React + Vite application, Tailwind CSS styling, bilingual translations, and civic interfaces. |
| **`backend`** | Express REST API server, database tables, validation logic, Edge functions, and tests. |
